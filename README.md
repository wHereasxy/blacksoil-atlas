# 黑土视界 · Black Soil Atlas

梨树县黑土地空天地数字孪生可视化网站，基于 Copernicus DEM、SoilGrids 2.0、Sentinel-2 与 NASA POWER 开放数据构建。

直接访问 GitHub Pages 即可浏览。网页为离线静态站点，主要交互包括三维地形、土壤六层剖面、碳储量、侵蚀情景和数据边界说明。

- [扩展分析报告](EXTENDED_REPORT.md)
- [数据分析报告](REPORT.md)
- [三维映射配置](outputs/vr_mapping.json)

页面中的侵蚀与保护效果为未本地校准的情景模型，不是实测治理成效；SoilGrids 原生约250米，30米为统一计算/显示网格。
